# Pokemon Card Collection App (PCCA)
This will include how-to instructions on installing and running the application

## Requirements
* Java: https://www.java.com/en/download/
* Scene Builder: https://gluonhq.com/products/scene-builder/
* IntelliJ: https://www.jetbrains.com/idea/download/?section=mac

## Running the Program
* Clone or download a zip file of the project 
* Within IntellJ:
  * simply open the -pokemon-card-collection folder
  * In your editor, find the "Build" button at the top and select "Build Project" 
  * Then, find MainApplication.java and run the program
